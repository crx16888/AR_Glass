## 运行
内网运行：
启动前端服务：http-server frontend -p 3000
启动后端服务：cd backend && node server.js 
http://localhost:3000/
外部运行：
http://47.97.183.238:3000

## 前端
实现了一个好感度监测系统，右边是需求，左边是展示出来的内容

## 后端
1. AI眼镜通过内置浏览器访问一个网页，即我们前端部署的http://47.97.183.238:3000
2. 网页通过 Web Audio API 获取麦克风声音流。
3. 声音数据实时压缩成小片段（200ms左右），通过 WebSocket 或 WebRTC 推送给电脑/服务器。
4. 服务器接收到音频片段后处理（语音识别/情绪分析等）。
5. 服务器处理结果通过 WebSocket 回传给网页，显示在眼镜浮窗。

浏览器直接web前端语音转文本识别，然后发送给服务器后端（服务器一直运行着后端就一直在着，前端是对外展示的那一面），后端调用大模型处理文本输出再发给前端更新
