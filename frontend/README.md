# 好感度监测系统 UI 设计文档

## 项目概述

这是一个实时好感度监测系统的前端界面，采用现代化的UI设计，提供直观的数据展示和用户体验。

## 详细设计规范

### 1. 左侧好感度显示区域 (主要区域)

#### 视觉特征
- **占屏比例**: 75% 宽度
- **背景**: 白色半透明卡片 (rgba(255, 255, 255, 0.95))
- **圆角**: 20px 圆角设计
- **阴影**: 深度阴影效果 (0 20px 40px rgba(0, 0, 0, 0.1))
- **动效**: 微光扫过效果 (shimmer animation)

#### 内容元素
1. **标题 "Happiness"**
   - 字体大小: 3.5rem
   - 字重: 300 (细体)
   - 颜色: #333
   - 字间距: 2px

2. **好感度数值**
   - 字体大小: 8rem (超大显示)
   - 字重: 700 (粗体)
   - 颜色: #4a90e2 (蓝色主题)
   - 文字阴影: 0 5px 15px rgba(74, 144, 226, 0.3)
   - 悬停效果: 1.05倍放大

3. **进度条**
   - 宽度: 80% 容器宽度
   - 高度: 20px
   - 背景: #e0e0e0
   - 填充: 渐变蓝色 (#4a90e2 到 #357abd)
   - 动画: 流光效果

#### 颜色系统
- **高好感度 (≥80)**: 绿色系 (#28a745)
- **中等好感度 (70-79)**: 蓝色系 (#4a90e2)
- **低好感度 (<70)**: 黄色系 (#ffc107)

### 2. 右侧需求内容面板

#### 视觉特征
- **占屏比例**: 25% 宽度
- **背景**: 白色半透明卡片
- **内边距**: 30px
- **布局**: 垂直排列

#### 内容结构
1. **面板标题**
   - 文字: "需求内容"
   - 字体大小: 1.8rem
   - 下边框: 2px 蓝色线条

2. **需求项目卡片**
   - 背景: 渐变灰色 (#f8f9fa 到 #e9ecef)
   - 左边框: 4px 蓝色强调线
   - 圆角: 15px
   - 悬停效果: 右移5px + 阴影

3. **状态指示器**
   - 圆形指示灯 (12px)
   - 蓝色 (#4a90e2)
   - 脉冲动画效果

### 3. 交互设计

#### 动画效果
1. **微光扫过**: 3秒循环的对角线光效
2. **进度条流光**: 2秒循环的水平光效
3. **状态指示器脉冲**: 2秒循环的透明度变化
4. **悬停效果**: 0.3秒缓动过渡

#### 实时更新
- **更新频率**: 每5秒自动更新
- **数值范围**: 60-90 随机生成
- **时间显示**: 实时本地时间
- **颜色联动**: 根据数值自动调整主题色

### 4. 响应式设计

#### 移动端适配 (≤768px)
- 布局改为垂直排列
- 好感度数值缩小至 5rem
- 标题缩小至 2.5rem
- 内边距调整为 10px

### 5. 技术实现

#### 前端技术栈
- **HTML5**: 语义化结构
- **CSS3**: 现代样式和动画
- **JavaScript**: 实时数据更新
- **响应式**: Flexbox 布局

#### 浏览器兼容性
- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

### 6. 设计理念

#### 视觉层次
1. **主要信息**: 好感度数值 (最大最醒目)
2. **次要信息**: 标题和进度条
3. **辅助信息**: 右侧详细内容

#### 用户体验
- **一目了然**: 核心数据突出显示
- **实时反馈**: 动态更新和动画效果
- **视觉愉悦**: 渐变色彩和流畅动画
- **信息层次**: 清晰的信息架构

#### 色彩心理学
- **蓝色**: 信任、稳定、专业
- **绿色**: 积极、成功、友好
- **黄色**: 注意、警示、中性

## 使用说明

1. 直接在浏览器中打开 `index.html` 文件
2. 系统会自动开始模拟好感度数据
3. 每5秒自动更新一次数值
4. 支持桌面和移动设备访问
